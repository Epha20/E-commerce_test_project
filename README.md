# E-commerce_Test_Project

This repository contains the complete solution for a comprehensive full-stack development test. It covers backend and frontend development, database design, Linux administration, AWS architecture and other suggestions asked to make.

---

### ## Key Concepts

* **Backend**: REST API Design, JWT Authentication, Role-Based Access, Concurrency, Horizontal Scaling and mongoDB schema.
* **Database challenge**: SQL Schema Design (MySQL), Query Optimization and mongoDB advantages for real-time leaderboard.
* **Frontend**: React component-based architecture, API data fetching and performance optimization.
* **Linux tests**: Command line operations, shell scripting for service monitoring, and other commands.
* **AWS**: Highly available architecture design, CI/CD with GitHub Actions, and IAM security principles.

---

### ## Folder Structure

The repository is organized into distinct sections to separate concerns:

* `/backend`: The Express REST API.
* `/frontend`: The React dashboard application.
* `/Database challenge`: SQL schemas.
* `/AWS`: Architecture and legends.
* `/Linux tests`: Documentation for scripts and their screenshots.
